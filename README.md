Strong Roots – Interactive Reader & Practice Test
A single-file HTML interactive learning application for "Strong Roots", an extract from Dr. A.P.J. Abdul Kalam's autobiography Wings of Fire.
This project integrates the full annotated text of Strong Roots, word-by-word English-to-Bengali translations, comprehensive grammar and comprehension quizzes, critical analysis, and interactive animations for answer verification.
🌟 Key Features
 * Interactive Text Reader with Bengali Word Meanings
   * Contains the complete text of Strong Roots including the author's biography, text introduction, and the main story.
   * Every word has interactive English-to-Bengali translation tooltips triggered on hover.
   * Includes full footnote references for key vocabulary.
 * 200 Multiple Choice Questions (MCQs)
   * Divided evenly into 4 sections (50 questions each):
     * Section 1: Reason & Assertion Questions.
     * Section 2: Story Sequence Rearrangement & True/False Statements.
     * Section 3: Grammar — Direct/Indirect Narration & Sentence Joining (Simple, Complex, Compound).
     * Section 4: Grammar — Sentence Splitting & Clause Identification.
 * Gamified Answer Verification
   * Correct Answer: Triggers an overlay animation hoisting the Indian National Flag with a "Jai Hind!" message.
   * Incorrect Answer: Triggers a Missile Launch & Blast animation with a "Mission Aborted!" message.
 * Critical Analysis Section
   * Deep dive into core thematic elements:
     * Synthesis of Faith and Rationalism.
     * Communal Harmony in Rameswaram.
     * Philosophical Foundations of Human Suffering & Introspection.
 * Single-File Standalone HTML
   * Zero external dependencies or frameworks required. Everything (HTML, CSS, JavaScript) is self-contained in a single file.
🚀 How to Run
 * Save the File: Save the generated HTML code as index.html (or any .html file name).
 * Open in Browser: Double-click the saved file or open it in any modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).
 * No Web Server Needed: It runs locally without needing an active internet connection or server setup.
📂 Structure of the Application
| Tab Name | Description |
|---|---|
| Interactive Reader | Full text with hoverable Bengali translations for every word and footnoted vocabulary. |
| Section 1 (50 MCQs) | Assertion and Reasoning evaluation based on Kalam's life and philosophy. |
| Section 2 (50 MCQs) | True/False statements and chronological event ordering. |
| Section 3 (50 MCQs) | Narration change and joining sentences into Simple/Complex/Compound forms. |
| Section 4 (50 MCQs) | Splitting complex sentences into simple ones and identifying clause types. |
| Critical Analysis | Detailed analytical commentary on the themes of Strong Roots. |
🛠️ Tech Stack
 * HTML5: Semantic layout and text structuring.
 * CSS3: Custom styles, responsive tabs, tooltip positioning, and pure CSS animations (Flag Hoisting & Missile Blast).
 * JavaScript (ES6): Dynamic MCQ generation, DOM event listeners for tooltip rendering, tab navigation, and answer validation logic.
